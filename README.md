# Daily Quotes App

## Description

Daily Quotes App is a React Native application built with Expo. The app allows users to enter their name and view motivational quotes retrieved from a public API.

## Features

* Three screens

  * Home Screen
  * Quotes Screen
  * About Screen
* API integration using DummyJSON Quotes API
* Form validation
* State management with useState
* FlatList for displaying quotes
* Basic styling using StyleSheet

## Technologies Used

* React Native
* Expo
* Expo Router
* JavaScript/TypeScript

## API Used

https://dummyjson.com/quotes

## How to Run

1. Install dependencies

npm install

2. Start the project

npx expo start

3. Open the app using Expo Go or an emulator.
